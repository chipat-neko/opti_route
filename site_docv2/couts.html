Trois scénarios commerciaux prêts à l'emploi

Combinaisons de modules calibrées pour les trois profils d'utilisateurs typiques. Coût récurrent total indiqué par scénario, déductible des charges de l'activité.

Disponible aujourd'hui

Scénario solo — livreur indépendant

Un chauffeur-livreur seul, en compte propre ou en sous-traitance. Outil de tournée personnel, sans besoin de partager les données.

  • Optimisation VROOM (500 tournées / jour offert)
  • OCR bordereaux et carnet d'adresses
  • Statistiques annuelles et facturation indicative
  • Sauvegardes ZIP portables

Coût opérationnel mensuel : 0 €

Phase 2 activable

Scénario équipe — petite coopérative

Un chef et 2 à 8 coéquipiers, synchronisation temps réel, tracking destinataire activé, carnet partagé.

  • Tout le scénario solo
  • Synchronisation cloud chef ↔ coéquipiers
  • Lien tracking court 20 caractères
  • Carnet partagé et historique commun
  • Notifications push (FCM gratuit)

Coût opérationnel mensuel : ≈ 25 € / mois

Détail : Supabase Pro 25 € + domaine tracking amorti (5 € / 12 mois).

Phase 3 activable

Scénario réseau — multi-dépôts

Plusieurs dépôts géographiques, direction réseau, intégration au TMS existant, facturation officielle TVA et reporting consolidé.

  • Tout le scénario équipe
  • Multi-dépôts avec isolation des données
  • Facturation officielle TVA et export comptable
  • API publique et webhooks vers le TMS
  • Notifications push et SMS destinataires
  • Dashboard consolidé direction

Coût opérationnel mensuel : 50 à 150 € / mois

Détail : Supabase Team 50 € + SMS au volume (variable).

Ce qui reste systématiquement gratuit

Quel que soit le scénario activé, certaines fondations restent toujours sans coût récurrent. Le socle Phase 1 est garanti à perpétuité.

Le socle Phase 1 complet

Optimisation des tournées, OCR bordereaux, mode chef d'équipe local, carnet d'adresses, statistiques annuelles, sauvegardes, sécurité PIN, mode hors-ligne. Aucune réintroduction de coût rétroactif.

Hébergement web statique

Le site et le dashboard CSV companion sont hébergés sur GitHub Pages, gratuit à vie pour des sites publics. Le dashboard parse les exports en mémoire côté navigateur, sans upload.

Open source du code applicatif

Le code source de l'application reste accessible. Cela garantit la pérennité même en cas d'arrêt de l'éditeur : quiconque peut récupérer, recompiler et continuer à maintenir l'outil.
